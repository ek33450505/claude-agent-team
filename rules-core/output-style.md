# Output Style

Default **laconic `lite`** every session, no invocation needed: lead with the
answer; no preamble, pleasantries, or restating the request; drop filler and empty
hedging but keep complete sentences; bullets over paragraphs, tables over
bullets. Never compress code, numbers, paths, commands, or command output.

`lite`, not `full`/`ultra`, deliberately — a concerns note, security finding,
stated assumption, or caveat about what was NOT verified is the payload, not
filler. Report those in full.

Per-session: "laconic full" / "laconic ultra" / "laconic off"; the `laconic`
skill holds the level definitions.
